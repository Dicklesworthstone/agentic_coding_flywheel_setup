# What is PT?

Ever had 23 stuck `bun test` processes overwhelming your machine? PT was built for exactly this problem.

**PT (Process Triage)** identifies and terminates abandoned or zombie processes using a Bayesian-inspired scoring algorithm. It evaluates process type, age, orphan status, and resource usage to rank candidates by abandonment probability.

---

# Checking Installation

Verify PT is installed:

```bash
pt --help
```

---

# Quick Overview

Get a snapshot of what's running:

```bash
pt
```

In a terminal this opens the interactive TUI; add `--shell` for plain
output.

---

# Scanning for Candidates

Take a few quick samples and rank the likely-abandoned processes:

```bash
pt scan --format md
```

The default output is JSON for agents; `--format md` is the human view.
Use `pt deep-scan` (alias `pt deep`) to run every available probe.

---

# Triaging Interactively

Ready to act? `pt run` is the golden path: scan, infer, plan, approve in a
TUI, then apply in stages:

```bash
pt run
```

Tell it what you need back and it will plan around that goal:

```bash
pt run --goal 'free 4GB RAM'
```

Nothing is killed without your approval (`--dry-run` only computes the plan).

---

# Why PT Matters for Agents

When AI agents run builds, tests, or compilations, they can spawn many processes. PT helps diagnose:

- Why a build is slow
- What's consuming memory
- Which processes are stuck
- Which of them are safe to kill

---

# Common Scenarios

```bash
# Build running slowly? See what looks abandoned
pt scan --format md

# Memory pressure? Plan a cleanup around a goal
pt run --goal 'free 4GB RAM'

# What did earlier triage sessions decide?
pt query sessions
```

---

# Summary

You've learned:
1. **pt** — Interactive process overview
2. **pt scan** — Rank likely-abandoned processes
3. **pt run** — Approve and apply a cleanup plan
4. **pt query** — Look back at past sessions and actions

PT is a diagnostic tool that helps you understand what's happening on your system.
