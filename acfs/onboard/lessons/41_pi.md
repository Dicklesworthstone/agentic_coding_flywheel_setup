# What is Pi?

Want a coding agent that starts instantly, runs as a single binary, and can even work with no API key at all? That's Pi.

**Pi (Pi Agent Rust)** is a native single-binary Rust port of the Pi coding agent. It streams responses with inline extended thinking and ships a full built-in toolset (read/write/edit/hashline_edit/bash/grep/find/ls, plus opt-in subagent/todo/ask).

---

# Checking Installation

Verify Pi is installed:

```bash
pi --version
```

The installer preserves any existing TypeScript pi as `legacy-pi` and adds an `rpi` launcher.

---

# Running a Task

Start an interactive session with a task:

```bash
pi "add input validation to the signup form"
```

For scripted, single-shot use (great inside automation):

```bash
pi -p "summarize the failing tests"
```

---

# Resuming Sessions

Pick up where you left off:

```bash
pi --continue
```

The `pir` alias does the same thing. A SQLite session index makes resuming even long sessions fast.

---

# Why Pi Matters for Agents

Pi is built for flexible, safe agent work:

- Supports many providers, including local models (ollama, llama.cpp, LM Studio) via `~/.pi/agent/models.json`, so an agent can run with no API key
- Capability-gated extension security with destructive-command mediation
- Single native binary: no Node runtime, fast startup
- Streaming output with inline extended thinking you can watch

# Common Scenarios

```bash
# Interactive session
pi "task description"

# Single-shot scripted mode for pipelines
pi -p "explain this stack trace"

# Resume the most recent session
pi --continue
```
