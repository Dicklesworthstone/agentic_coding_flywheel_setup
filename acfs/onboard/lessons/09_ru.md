# RU: Multi-Repo Mastery

**Goal:** Sync dozens of repos with one command and automate commits with AI.

---

## Why RU Matters

Managing multiple repos manually is tedious:
- cd into each repo
- git pull
- Check for conflicts
- Repeat 20+ times

RU does this in seconds with parallel workers.

---

## Essential Commands

### Sync All Repos

```bash
# Basic sync (clone missing + pull updates)
ru sync

# Parallel sync with 4 workers (4x faster)
ru sync -j4

# Auto-stash local changes before pull
ru sync --autostash
```

### Check Status

```bash
# Quick status check
ru status

# Fetch remote + show ahead/behind counts
ru status --fetch
```

### Resume Interrupted Sync

```bash
# Continue from where you left off
ru sync --resume
```

## Commit Sweep: Logical Commits Across Repos

The killer feature. RU groups the dirty worktrees across your repos into
logical conventional commits.

### Preview First

`ru commit-sweep` is a dry run by default, so previewing is the default:

```bash
ru commit-sweep
```

This prints the planned commits per repo without touching anything.

### Run Commit Sweep

```bash
# Execute the planned commits
ru commit-sweep --execute

# Only sweep repos matching a glob pattern
ru commit-sweep --repos='*_rust' --execute

# Keep files you staged by hand as their own commit group
ru commit-sweep --respect-staging --execute
```

### How It Works

1. **Discover**: RU finds every configured repo with a dirty worktree
2. **Plan**: Changes are grouped into logical conventional commits
3. **Execute**: With `--execute`, RU makes the planned commits with git

## Configuration

RU uses XDG conventions. Config lives in `~/.config/ru/`.

### Main Config

```bash
# ~/.config/ru/config
PROJECTS_DIR=/data/projects
PARALLEL=4
UPDATE_STRATEGY=ff-only
AUTOSTASH=false
```

### Repo Lists

```bash
# ~/.config/ru/repos.d/public.txt
Dicklesworthstone/ntm
Dicklesworthstone/beads_viewer
owner/repo@develop
owner/repo as my-fork
```

## Exit Codes

For scripting and automation:

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | Partial failure (some repos failed) |
| 2 | Conflicts (manual resolution needed) |
| 5 | Interrupted (use --resume) |

## Daily Workflow

A typical morning with RU:

```bash
# 1. Sync all repos (2 minutes for 20+ repos)
ru sync -j4

# 2. Check what needs attention
ru status --fetch

# 3. (Optional) Commit dirty repos: preview, then execute
ru commit-sweep
ru commit-sweep --execute
```
